#  At any time during the game:
Enter **/exit** or press **ctrl + d**, **ctrl + c**, or **ctrl + z** to exit the game.<br>
Enter **/clear** to clear the text off your screen (and show your list of cans again, if it's set up).<br>
Capitalization and beginning/ending spaces of your inputs don't matter.<br>
Short example video of real-life gameplay of this game (which inspired this program):<br>
&nbsp;&nbsp;&nbsp;&nbsp;https://www.youtube.com/shorts/TqLawfXbG9E<br>
Enter **/restart** to restart the game and show this message again.<br>
Enter **/help** to show this message again.
